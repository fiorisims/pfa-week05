# pfa-week05
Fiori Sims Week 5 Homework for Programming for Animators FA26 
Photoshop Bridge
How to run: Open Terminal, ask agent to run test_human_viewer.py. Adjust model to personal liking and then click "import to photoshop". This imports the image you created in the viewport into Photoshop as a png. 
Asked agent to create a bridge between the terminal and Photoshop and add a GUI interface with a rotatable, simple 3d model. This process used Maya to create the model and Pygame to create the GUI.
